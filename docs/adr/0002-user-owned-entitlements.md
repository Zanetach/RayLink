# Store entitlement settings on each user

RayLink will model traffic allowance, expiry, device limit, and node scope as a User Entitlement owned by one User. The management UI and API configure these fields while creating or editing that User; there is no reusable Plan resource, assignment workflow, or Plan management page. Client subscription formats are a platform-wide capability: every User receives the universal Mihomo, Egern, and sing-box formats, and administrators do not grant them per User. Existing SQLite installations retain the old Plan table, foreign key, and client-format column only as an internal migration compatibility layer, while all runtime, portal, and API behavior reads the user-owned fields and exposes the universal formats. This supersedes the Plan relationship assumed by ADR 0001; its single-host runtime-adapter decision remains unchanged.
