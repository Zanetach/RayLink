# RayLink v0.2.13

本版本交付通用多客户端订阅、稳定的协议健康判断，以及可自动回滚的控制面升级流程。

## 一个订阅地址，多客户端使用

- 同一个用户订阅地址自动支持 Clash/Mihomo、Egern 和 sing-box JSON。
- 支持显式格式参数：`mihomo`、`egern`、`egern-profile`、`singbox`。
- 浏览器打开订阅地址时显示客户端选择页，旧版 `/sing-box.json` 路径继续兼容。
- 管理端和用户中心均可查看持久订阅链接、二维码、一键导入并主动重新生成。
- 订阅 bearer 继续使用 AES-256-GCM 加密保存，响应禁止公开缓存。

## 协议健康与智能回退

- “延迟”统一为更准确的“连接耗时”，使用多次采样中位数。
- 连续失败后才判定超时，同时展示抖动、可用率和最近探测时间。
- 默认优先稳定 TCP 组；UDP 线路健康时允许 Hysteria2/TUIC 参与选择，异常时自动回退。
- 协议真实握手、端口监听和公网探测状态保持分层展示。

## 安全升级

- 同一条一键安装命令会自动识别全新安装或已有控制面升级。
- 升级期间 sing-box Runtime 保持运行，已连接代理不因控制面替换而中断。
- 升级前备份应用、数据和 systemd 服务单元。
- 新版本完成语法校验、服务启动和本机 API 健康检查后才确认成功。
- 任一步骤失败会自动恢复上一版本和升级前数据。

## 升级命令

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.13/install.sh | bash'
```

升级备份保存在 `/var/backups/raylink/`。
