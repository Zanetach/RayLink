# RayLink v0.2.27

本版本为通用用户订阅增加 Loon 原生节点格式，同时保持现有 Mihomo、Egern 和 sing-box
格式不变。

## Loon 节点订阅

- 通用订阅地址会识别 Loon User-Agent，也可显式追加 `?format=loon`。
- 支持 Shadowsocks、VMess、VLESS、Trojan、AnyTLS 和 Hysteria 2。
- 自动忽略 Loon 当前不兼容的 TUIC 与旧 Hysteria 节点，避免整个订阅解析失败。
- 管理员用户详情和用户中心均提供 Loon 订阅入口。
- Loon 格式只交付节点，不覆盖客户端已有的策略组、规则和 DNS。

## 升级命令

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.27/install.sh | bash'
```

升级前会备份应用、数据和 systemd 服务单元；健康检查失败时自动回滚。
