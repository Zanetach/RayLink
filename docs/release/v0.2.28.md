# RayLink v0.2.28

本版本将 Loon 入口调整为无参数、无扩展名的通用订阅地址，并集中管理服务端客户端格式目录。

## 干净的 Loon 地址

- 管理端、用户中心、订阅 API 和浏览器选择页不再给 Loon 地址追加 `format` 参数。
- Loon 直接使用原始通用订阅地址，由 User-Agent 自动返回原生节点格式。
- 显式 `?format=loon` 和 `/loon.list` 继续兼容已有配置。
- Mihomo、Egern 和 sing-box 的现有地址与响应保持不变。

## 升级命令

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.28/install.sh | bash'
```

升级前会自动备份应用与数据；健康检查失败时恢复上一版本。
