# RayLink v0.2.32

本版本修复 FlClash / Mihomo 1.19.30 拒绝加载订阅生成配置的问题。

## Mihomo DNS 规则修复

- `.local`、`.lan`、`.home.arpa` 等本地域名后缀改用 Mihomo 支持的
  `+.suffix` 形式。
- 自定义直连路由中的 `domain_suffix` 同步使用 `+.suffix`，避免生成
  `domain:*.suffix` 这类无效规则。
- 精确域名规则保持不变，不影响原有分流语义。

## 升级命令

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.32/install.sh | bash'
```

升级完成后，无需更换订阅地址；在客户端刷新原订阅即可。
