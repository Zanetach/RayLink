# RayLink v0.2.1

v0.2.1 完成全新 VPS 的一键安装与浏览器首次初始化闭环，并将控制台、订阅服务和
Host 节点连接地址拆分为独立、可配置的地址角色。

## 新增与改进

- 一键安装自动部署 RayLink、Caddy、Node.js 22 和预编译的 sing-box 1.13.14
  计量版 Runtime。
- 安装完成后输出 30 分钟有效的一次性初始化链接；服务端仅保存令牌哈希。
- 全新首次初始化界面，可完成访问入口、管理员、本机 Runtime 和预检查配置。
- Caddy 在初始化过程中验证域名解析、申请 HTTPS 证书，并在失败时恢复原配置。
- 控制台地址和订阅地址作为全局配置分别管理；订阅域名仅开放订阅与规则文件路径。
- 每台 Host 独立维护节点连接域名或公网 IP，一个用户配置可聚合多个 Host。
- 修复浏览器原生校验提示，统一使用 RayLink 界面内的字段错误信息。

## 安装

当前 Release 提供 Linux AMD64 安装包。使用全新 Debian/Ubuntu VPS，并开放 TCP
80、443 以及计划启用的协议端口：

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.1/install.sh | bash'
```

安装器会校验发布包 SHA-256，完成后在终端输出：

```text
https://服务器公网IP/setup#token=一次性初始化令牌
```

IP 首次入口使用本机签发证书。继续访问前，请核对安装器同时打印的 SHA-256 证书指纹。

## 已知边界

- 当前正式安装包仅提供 Linux AMD64。
- 从 IP 初始化入口切换到新的控制台域名时，浏览器会跳转到新域名并要求使用刚创建的
  管理员账号登录。
- 干净 VPS、真实公网协议连接和长时间故障验收仍应按生产验收清单执行。
