# RayLink v0.2.29

本版本修复启用 Fake-IP DNS 时，客户端把节点服务器域名映射到保留地址并导致全部节点测速超时的问题。

## 节点拨号地址

- 本地 Host 的客户端订阅使用服务器公网 IP 作为实际拨号地址。
- 协议配置、Host 域名和 TLS SNI 保持不变，证书校验继续使用 `node.cyclelink.org`。
- Loon、Mihomo、Egern 和 sing-box 共享同一修复；无参数、无扩展名的 Loon 订阅地址不变。
- 新安装自动保存公网 IP；从旧版本升级时自动补写，升级失败会恢复原环境文件。

## 升级命令

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.29/install.sh | bash'
```

升级前会自动备份应用、数据、systemd 服务单元和需要迁移的环境文件；健康检查失败时恢复上一版本。
