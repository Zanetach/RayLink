# RayLink v0.2.31

本版本修复 Loon 节点全部显示 `Failed` 的 TLS SNI 兼容问题。

## Loon 订阅修复

- VMess、VLESS、Trojan、AnyTLS 与 Hysteria 2 统一使用 Loon 当前原生字段 `sni`。
- Loon 继续使用健康公网 IP 拨号，同时保留 Host 域名作为证书校验身份。
- 保持证书校验开启，不需要更换现有订阅地址或降低 TLS 安全性。

## 升级命令

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.31/install.sh | bash'
```

升级完成后，在 Loon 中刷新原订阅即可获取修正后的节点格式。
