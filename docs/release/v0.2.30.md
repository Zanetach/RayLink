# RayLink v0.2.30

本版本将固定公网 IP 升级为智能端点：Host 继续显示域名，服务端自动维护客户端实际拨号 IP，
解决 FlClash、Loon 等 Fake-IP 客户端订阅成功但全部节点超时的问题。

## 智能端点

- 通过可信 DNS 解析 Host IPv4，遵循记录 TTL，并对已启用 TCP 协议端口进行健康检查。
- 将最后一次可用 IP 持久化到数据目录；DNS 或健康检查失败时先使用该记录，再使用安装时保存的公网 IP。
- FlClash/Mihomo 保留节点域名，注入 hosts 映射、节点 DNS 策略和 Fake-IP 排除。
- sing-box 保留节点域名，通过专用 hosts DNS 和 `domain_resolver` 拨号。
- Loon/Egern 使用健康 IP 拨号，同时保留原 TLS SNI 和证书校验域名。
- 通用订阅地址保持无参数、无扩展名，并继续根据 User-Agent 自动选择格式。

## 升级命令

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.30/install.sh | bash'
```

升级会保留现有域名、订阅地址和公网 IP 回退配置；健康检查失败时自动恢复上一版本。
