# RayLink v0.2.0

v0.2.0 聚焦品牌一致性、管理员会话安全和正式发布体验。

## 新增与改进

- 全新的 RayLink 品牌标识，统一应用到管理控制台、登录、首次初始化、用户中心与站点图标。
- 管理员菜单新增安全退出；服务端立即撤销当前会话，其他浏览器会话不受影响。
- 会话过期后前端清理登录态并返回登录页，不再保留不可用的管理界面。
- 运维和系统页面移除不必要的内部滚动条，长页面由浏览器统一滚动。
- 新增仓库首页 README、真实产品截图、架构图、一键安装和多节点使用说明。

## 安装包

本次发布提供 Linux AMD64 安装包，内含预编译的 sing-box 1.13.14 计量版 Runtime。
安装前必须使用同页 `.sha256` 文件验证包完整性。

## 升级说明

v0.1.0 已部署环境继续使用原配置和数据。当前控制面安装器用于全新安装，不会覆盖
`/opt/raylink`；已有环境应先备份 `/var/lib/raylink` 与 `/etc/raylink`，再按发布包
内容升级应用文件并重启 `raylink.service`。
