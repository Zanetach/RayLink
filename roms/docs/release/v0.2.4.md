# RayLink v0.2.4

v0.2.4 将 Host 协议启用升级为可回滚的一键事务，并为 UDP 协议增加真实握手探针。

## 新增

- 协议按“一键启用、仅本机、高级协议”分组，界面展示配置、发布、监听和公网可用状态。
- 自动选择空闲端口，生成用户凭据与 Reality 密钥，配置 TLS、ACME 和 TCP/UDP 防火墙。
- 自动执行 `sing-box check`、原子发布、服务重启、端口监听与公网连通性检查。
- 远程节点发现端口冲突后在本机扫描下一空闲端口，控制面自动使用建议端口重试。
- Hysteria、TUIC、Hysteria2 使用独立内部探针凭据，通过 `sing-box tools fetch` 完成真实协议握手和外部 HTTPS 请求。
- `RAYLINK_PROTOCOL_PROBE_URL` 可自定义外部探针地址，默认为 Google 204 健康检查。
- RayLink Node 升级至 0.7.0；旧版 Node 会暂停领取任务并提示升级。

## 安全与恢复

- 探针凭据不属于普通用户，不进入订阅，也不计入用户数量。
- 探针临时配置权限为 `0600`，执行结束后立即删除。
- 探针最多重试三次；端口、证书、协议握手或外部请求任一步失败，自动恢复上一份配置及 RayLink 新增的防火墙规则。
- 本机节点复用 Caddy 证书，远程节点使用 sing-box ACME，并自动维护 HTTP-01 / TLS-ALPN-01 所需的 TCP 80/443 规则。

## 验证

- 146 项自动化测试全部通过。
- sing-box 1.13.14 全协议、Reality、ACME 及三种 UDP 探针配置检查通过。
- 3500 次持续请求后堆内存无净增长，活动句柄为 0。
- 安装脚本语法、发布包依赖和 SHA-256 校验通过。

## 安装

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.4/install.sh | bash'
```

当前正式安装包支持 Debian/Ubuntu、systemd 和 Linux AMD64。
