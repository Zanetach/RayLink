# RayLink v0.2.2

v0.2.2 是首次初始化入口的生产修复版本。问题与修复均已在全新 Ubuntu 24.04
AMD64 VPS 上复现和验证。

## 修复

- 首次 IP HTTPS 入口改为显式证书的 `:443` 默认站点，使不发送 SNI 的浏览器和
  HTTP 客户端也能完成 TLS 握手。
- 保留面向服务器公网 IP 的 HTTP 到 HTTPS 重定向。
- 检测到 UFW 已启用时，一键安装自动放行 TCP 80 和 443，并附加 RayLink 规则说明。
- 保持 RayLink 只监听 `127.0.0.1:4173`，控制面仍只通过 Caddy 对外提供服务。

## 验证

- Ubuntu 24.04、Linux 6.8、AMD64 全新 VPS 一键安装完成。
- RayLink、Caddy 与 sing-box 1.13.14 服务状态正常。
- 无 SNI 的本机 HTTPS 请求通过。
- 外网直接访问 `/api/setup/status` 返回 HTTP 200。
- UFW 仅新增控制面所需的 80/443 规则，原有 SSH 规则不变。

## 安装

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.2/install.sh | bash'
```

当前正式安装包支持 Debian/Ubuntu、systemd 和 Linux AMD64。
