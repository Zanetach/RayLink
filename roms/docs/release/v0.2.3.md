# RayLink v0.2.3

v0.2.3 为首次初始化增加可恢复的真实进度状态。

## 新增

- Step 5 展示 Runtime 发布、Caddy/HTTPS 配置、管理员与 Host 数据落库三个阶段。
- `GET /api/setup/status` 在初始化期间返回服务端持久化进度、当前阶段和更新时间。
- 页面每 900 毫秒同步一次状态；刷新、短暂断网或 Caddy 切换入口后可继续查看。
- 初始化成功显示 100% 后进入控制台；失败则恢复为可重试状态。

## 验证

- 覆盖 `INITIALIZING` 状态的持久化、API 查询与失败恢复。
- 覆盖 Caddy 激活期间对真实 `access` 阶段的并发查询。
- 完成初始化页面的桌面端视觉检查。
- 通过完整生产检查、协议矩阵检查与内存稳定性测试。

## 安装

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/Zanetach/RayLink/releases/download/v0.2.3/install.sh | bash'
```

当前正式安装包支持 Debian/Ubuntu、systemd 和 Linux AMD64。
