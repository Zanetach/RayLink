# RayLink v0.2.12

本版本修复协议节点超时，并让管理员和用户在登录后直接查看现有订阅地址。

## 订阅访问

- 订阅 bearer 凭据使用独立密钥执行 AES-256-GCM 加密，数据库继续保留摘要用于访问校验。
- 管理员可在用户列表或用户详情中查看现有链接和二维码。
- 用户中心登录后自动读取现有链接和二维码。
- 只有明确点击“重新生成订阅地址”才会撤销旧地址，并在操作前提示旧客户端立即失效。
- 旧版本只保存摘要的地址无法逆向恢复；升级后需要重新生成一次，之后即可持续查看。

## 协议兼容性

- VMess、VLESS、Trojan 和 AnyTLS 的一键启用默认改为节点域名的标准证书 TLS。
- 本机 Host 复用 Caddy 管理的节点证书；远程 Host 由 sing-box ACME 管理证书。
- Reality 仍保留在高级协议编辑能力中，但不再作为上述协议的一键默认值。
- TCP 与 UDP 公网协议均通过 `sing-box tools fetch` 执行真实握手和外部请求，
  不再把“端口可连接”等同于“协议可用”。
- 变更规避 sing-box 1.13.x 客户端与服务端 Reality 组合出现
  `processed invalid connection` 的互操作问题。

## 升级说明

升级前请备份 `/var/lib/raylink`。新安装会自动生成
`RAYLINK_SUBSCRIPTION_ENCRYPTION_KEY`；已有安装必须在首次启动 v0.2.12 前固定配置该密钥，
否则生产进程会拒绝启动。可执行
`sudo bash deploy/migrate-default-tls.sh`，包装脚本会加载真实生产环境并使用内置 Node.js，
逐协议原子迁移已启用的 VMess、VLESS、Trojan 和 AnyTLS；每个协议都必须通过真实握手
探针，否则恢复当前协议的原配置。
