# RayLink v0.2.0 生产候选验收记录

验收日期：2026-07-27

结论：代码级生产检查通过；版本仍是生产候选，不应在干净 Linux VPS、真实客户端和长时间故障验收完成前标记为“正式商用已验收”。

## 已通过的自动化验收

| 范围 | 结果 | 证据 |
|---|---|---|
| 控制面、首次初始化、登录与退出、User Entitlement、Host、RayLink Node、Deployment、回滚、TLS、计量、升级 | 通过 | `npm run check`：108/108 |
| 空数据库 API 闭环 | 通过 | 进程内自动创建 Host、模拟注册 RayLink Node、启用协议、创建用户、设置配额/到期/范围、发布、模拟完成远程任务、登录用户中心、生成多 Host 配置 URL；不等同于 VPS 安装验收 |
| 服务端协议语法 | 通过 | sing-box 1.13.14 对界面 17 种 inbound 逐项执行 `sing-box check`，并额外验证 VMess、Trojan、VLESS、AnyTLS 的 Reality 组合 |
| 客户端协议与智能路由语法 | 通过 | 12 种用户侧协议合并生成 TUN、DNS、URLTest、Selector 配置并执行 `sing-box check`；语法通过不等同于真实公网连接通过 |
| HTTP 内存烟测 | 通过 | 每次包含 6 个用户的 3500 次 `/api/bootstrap` 请求；本次终验 heap -130,248 B、RSS +20,021,248 B、external -5,813 B、活动句柄无增长；不替代 72 小时多负载验收 |
| 长期数据边界 | 通过 | 过期管理员/用户会话清理；Deployment 与已完成 RayLink Node 任务按类型保留最近 50 条；原始流量明细保留 30 天、日汇总保留 400 天，累计配额长期保留；超过 7 天的样本拒绝重放 |
| 控制面不可达 | 通过 | RayLink Node 单次请求 30 秒超时，错误响应保留控制面真实错误消息 |

完整检查命令：

```bash
npm run check:production
```

协议检查需要 PATH 中存在 sing-box 1.13.14，或显式设置：

```bash
SING_BOX_BIN=/usr/local/bin/raylink-sing-box npm run check:protocols
```

## 仍需外部环境验收

以下项目无法仅在本机自动化环境中替代，发布为正式商用版本前必须留存实际记录：

- Ubuntu 22.04/24.04 与 Debian 12 的全新 AMD64 VPS 一键安装。
- 第二台公网 VPS 的一次性接入、断线重连、任务失败回滚与在线升级。
- VLESS + Reality、Trojan + TLS、Hysteria2 的真实公网客户端连接。
- TUN 下中国站点直连、其他目标代理、DNS 防泄漏、URLTest 故障切换。
- Runtime 重启、RayLink Node 断网、控制面重启、磁盘满和错误证书的故障注入。
- 真实用户计量在跨 Host、重复上报、Runtime 重启场景的 72 小时持续运行。
- 数据库和 TLS 资产备份恢复。
