# RayLink Web

RayLink Web 由同源 Node.js 控制面直接提供，当前覆盖：

- 运行仪表盘与节点健康状态
- “用户与订阅”统一工作区，包含用户管理和方案管理两个标签
- 用户、有效期与订阅方案分配
- 流量、设备、节点范围和客户端能力方案
- 用户中心登录与客户端导入流程
- 主机拓扑、sing-box 安装检测和 17 种入站能力目录
- 多协议表单、Reality 密钥、TLS/Transport 和高级 JSON
- 配置校验、快照、原子发布、历史回滚和健康确认轨迹

## 本地运行

项目不依赖前端构建工具，但数据与操作依赖同源 API。请从仓库根目录运行：

```bash
npm start
```

随后访问 `http://127.0.0.1:4173/`。

## 文件结构

- `index.html`：四个核心工作区的语义化结构
- `styles.css`：响应式设计系统与全部组件样式
- `app.js`：API 数据绑定、筛选、协议表单、安装、发布和回滚交互
- `DESIGN.md`：颜色、排版、组件和响应式规范

开发环境会初始化演示用户；生产环境不写入演示数据。Runtime 使用 `dry-run` 或
`systemd` 模式，具体部署方式见仓库根目录 `README.md`。
