# RayLink web prototype

RayLink 是一个面向 sing-box 多用户管理系统的高保真前端原型，当前覆盖：

- 运行仪表盘与节点健康状态
- 用户、配额、有效期和协议权限管理
- Clash / Mihomo、sing-box 与原始 URI 订阅设置
- 主机拓扑、协议入口与节点详情
- 配置校验、快照、分批发布和健康确认轨迹

## 本地运行

项目不依赖构建工具。在本目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

随后访问 `http://127.0.0.1:4173/`。

## 文件结构

- `index.html`：五个核心页面的语义化结构
- `styles.css`：响应式设计系统与全部组件样式
- `app.js`：筛选、抽屉、表单校验、复制与发布演示逻辑
- `DESIGN.md`：颜色、排版、组件和响应式规范

当前版本使用示例数据，不会连接或修改真实 sing-box 节点。接入生产后端时，建议将页面状态替换为 API 数据，并通过 WebSocket 或 SSE 接收节点状态与发布事件。
